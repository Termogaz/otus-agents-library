# DESIGN.md

Визуальная система интерфейса библиотеки. Описывает правила, а не отдельные страницы: что где показывать, решает
`docs/handoff/ux-patterns.md`. Решения автора D-06..D-09 — в `06-CONTEXT.md` фазы 6.

Правило реализации (NFR-3): цвета и отступы берутся только из токенов этого файла. Если значения не хватает, сначала
меняется этот файл.

## Характер

Тихий рабочий инструмент библиотекаря: светло-голубой фон, белые карточки, тёмно-зелёный акцент, голубая шапка таблиц.
Цвет не украшает, а сообщает: оранжевым становится только проблема. Плотность средняя, таблица читается как журнал выдач.

## Цвета и роли

| Токен                    | Роль                                                  |
| ------------------------ | ----------------------------------------------------- |
| `--color-bg`             | Фон страницы, подвал                                  |
| `--color-surface`        | Карточки разделов, поля, вторичная кнопка             |
| `--color-surface-muted`  | Шапка таблицы                                         |
| `--color-text`           | Основной текст                                        |
| `--color-text-muted`     | Подсказки, шапка таблицы, подвал, строка «Возвращена» |
| `--color-border`         | Границы карточек и строк: декоративные                |
| `--color-border-control` | Граница полей: должна быть различима                  |
| `--color-accent`         | Главная кнопка, текст вторичной кнопки, фокус         |
| `--color-accent-tint`    | Подтверждение, наведение на вторичную кнопку          |
| `--color-danger`         | Текст ошибки и статуса «Просрочена»                   |
| `--color-danger-bg`      | Сообщение об ошибке, просроченная строка              |
| `--color-danger-border`  | Граница сообщения об ошибке                           |
| `--color-warn-bg`        | Сообщение «Сохранено, но список не обновился»         |

Зелёный не означает «всё хорошо» в таблице: «На руках» — обычный текст (D-07). Подтверждение действия использует акцент,
потому что это ответ на действие, а не статус записи. Тёмной темы нет.

Красного в палитре нет: проблему обозначает оранжевая гамма, а смысл всегда несёт текст. Оранжевый `#F9A620` на белом даёт
только 2.00, поэтому как текст не используется: текст ошибки — его тёмный оттенок `#7A4100`. `#548C2F` под белым текстом
даёт 4.06, ниже порога, поэтому главная кнопка — `#104911`, а `#548C2F` остаётся границей поля.

## Типографика

Шрифт — IBM Plex Sans (D-08), начертания 400, 500, 600. Других начертаний не использовать: браузер будет их имитировать.

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600&display=swap"
  rel="stylesheet"
/>
```

Кириллица проверена 2026-10-31: CSS Google Fonts отдаёт наборы `cyrillic` и `cyrillic-ext` для всех трёх начертаний.
Без интернета работает системный шрифт из `--font-sans`, вёрстка не должна зависеть от ширины конкретного шрифта.
Ссылка делает запрос к серверам Google при открытии страницы; это принятая цена решения D-08.

| Роль             | Размер        | Начертание | Высота строки | Элемент                 |
| ---------------- | ------------- | ---------- | ------------- | ----------------------- |
| Страница         | `--text-xl`   | 600        | 1.2           | `h1` «Библиотека»       |
| Раздел           | `--text-lg`   | 600        | 1.3           | `h2`                    |
| Основной         | `--text-base` | 400        | 1.5           | Ячейки, поля, сообщения |
| Подпись и кнопка | `--text-base` | 500        | 1.5           | `label`, `button`       |
| Шапка таблицы    | `--text-sm`   | 500        | 1.4           | `th`                    |
| Мелкий           | `--text-sm`   | 400        | 1.4           | Подсказки FR-6, подвал  |

Статус «Просрочена» — 600. Даты и числа в таблицах — `font-variant-numeric: tabular-nums`. `caption` таблиц остаётся в
разметке для e2e и скрывается визуально, без `display: none`.

## Отступы и раскладка

- Шкала кратна 4 px: только `--space-*`. Внутри карточки `--space-6`, между карточками `--space-6`, поле и его подсказка
  `--space-1`, между полями `--space-4`.
- Контент не шире `--content-width`, по центру. Боковое поле страницы `--space-6`, ниже 768 px — `--space-4`.
- Раскладка: «Выдачи» на всю ширину, «Книги» и «Читатели» в две колонки 5:3; ниже 768 px одна колонка (D-01). Пропорция
  найдена на макете: при равных колонках на 1280 px таблица книг прокручивалась и столбец «Свободно» уходил за край.
- Форма выдачи при ширине от 768 px — одна строка: два поля и кнопка на уровне полей, подсказки FR-6 ниже.
- Поля форм книги и читателя идут столбцом. Кнопка формы шириной по тексту, ниже 768 px — на всю ширину.

## Форма и глубина

Скругление: `--radius-control` у полей, кнопок и сообщений, `--radius-card` у карточек. **Теней нет:** карточки отделяются
от фона цветом и границей 1 px `--color-border`. Анимаций нет: итог появляется сразу, прокрутка мгновенная.

## Компоненты и состояния

Фокус для всех элементов управления: `:focus-visible`, контур 2 px `--color-accent`, отступ 2 px. Контур не убирается.

| Компонент        | Default                                 | Hover                | Active               | Disabled                                 | Error                                             |
| ---------------- | --------------------------------------- | -------------------- | -------------------- | ---------------------------------------- | ------------------------------------------------- |
| Главная кнопка   | Фон `accent`, текст `on-accent`         | Фон `accent-hover`   | Фон `accent-active`  | Фон `disabled-bg`, текст `disabled-text` | Своего состояния нет, рядом сообщение             |
| Вторичная кнопка | Фон `surface`, текст и граница `accent` | Фон `accent-tint`    | Текст `accent-hover` | Фон `disabled-bg`, текст `disabled-text` | Своего состояния нет, над таблицей сообщение      |
| Поле и список    | Фон `surface`, граница `border-control` | Граница `text-muted` | Граница `accent`     | Не используется: формы всегда доступны   | `:user-invalid`: граница `danger`                 |
| Строка таблицы   | Фон `surface`, граница снизу `border`   | Без изменений        | Без изменений        | —                                        | Просрочена: фон `danger-bg`, статус `danger`, 600 |

Кнопки: `--control-height`, поле по горизонтали `--space-4`. Кнопка «Вернуть» — вторичная, высота
`--button-compact-height`, чтобы вошла в строку. Заблокированная кнопка: `cursor: not-allowed`, текст не меняется.

**Сообщения.** Полоса на всю ширину блока, поле `--space-3`, основной размер текста.

| Вид                  | `role`   | Фон           | Текст    | Граница 1 px    |
| -------------------- | -------- | ------------- | -------- | --------------- |
| Ошибка               | `alert`  | `danger-bg`   | `danger` | `danger-border` |
| Подтверждение        | `status` | `accent-tint` | `accent` | `accent`        |
| Сохранено без списка | `status` | `warn-bg`     | `text`   | `warn-border`   |

**Таблицы.** `--row-height` (D-09) — минимальная высота строки: длинный текст переносится, и строка растёт. Кнопка в ячейке
блочная, иначе базовая линия увеличивает строку до 48,5 px. Ячейка `--space-3` по горизонтали, текст по левому краю. Шапка:
`surface-muted`, текст `text-muted`. Блок таблицы прокручивается сам (`overflow-x: auto`) и доступен с клавиатуры.

**Статусы выдачи** (D-07): текст есть всегда, цвет только дополняет его.

| Статус                  | Строка                            | Текст статуса     |
| ----------------------- | --------------------------------- | ----------------- |
| «Просрочена»            | Фон `danger-bg`, текст `text`     | `danger`, 600     |
| «На руках»              | Фон `surface`, текст `text`       | `text`, 400       |
| «Возвращена ДД.ММ.ГГГГ» | Фон `surface`, текст `text-muted` | `text-muted`, 400 |

**Подсказки FR-6.** Мелкий текст `text-muted`. Высота строки зарезервирована и при пустой подсказке.

**Пустой список и загрузка.** Основной текст `text-muted` с полем `--space-4`, без рамок и иллюстраций.

**Подвал.** Мелкий текст `text-muted` на фоне страницы, `API: ok` виден всегда.

## Тон текста

- Коротко и по делу: сначала результат или причина. «Нет свободных экземпляров», а не «К сожалению, выдать книгу не удалось».
- Без «успешно», «пожалуйста» и восклицательных знаков. Кодов ошибок пользователь не видит.
- Текст ошибки объясняет причину, пустой список — следующий шаг.
- Кнопка называет действие глаголом: «Выдать», «Вернуть», «Добавить».
- Названия книг — в кавычках «ёлочках», даты — ДД.ММ.ГГГГ.
- Точные формулировки — в `docs/handoff/ux-patterns.md`.
