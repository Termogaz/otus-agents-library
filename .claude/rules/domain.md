# Правила для `src/domain/`

Домен — чистые бизнес-правила библиотеки: лимит книг на читателя, срок выдачи, просрочка,
доступность экземпляра. Здесь нет I/O и фреймворков.

## Запрещено

- Импортировать `express`, `react`, `react-dom`, `fs`, `node:fs`, `path`, `node:path`,
  `http`, любые другие модули с I/O.
- Импортировать что-либо из `src/server/` или `src/client/`.
- Вызывать `new Date()` / `Date.now()` внутри правил — текущее время приходит параметром
  `now: Date`.
- Читать или писать хранилище напрямую. Если правилу нужны данные — они передаются аргументом,
  а сохранение делает `server` через интерфейс репозитория.
- Возвращать отказ строкой или бросать безымянный `Error`.

## Как писать

- Чистые функции и типы; вход — данные, выход — новый результат (без мутации аргументов).
- Ожидаемый отказ — типизированный результат (`{ ok: false, code: 'NO_FREE_COPIES' }`)
  или собственный класс ошибки с полем `code`.
- Каждое правило — через TDD: сначала падающий тест в `tests/unit/`, затем код.

Если задача требует I/O в домене — не обходить правило, а предложить вынести I/O в `server`.
