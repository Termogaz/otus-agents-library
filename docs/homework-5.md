# ДЗ-5. Бэкенд-разработка с AI-агентом

Текст задания курса OTUS «ИИ-агенты: продвинутое внедрение и использование», модуль 5.

## Цель

Собрать backend своего проекта с агентом: от схемы данных до работающей AI-фичи.

## Пошаговая инструкция

1. Спроектирована схема данных из PRD: сущности, связи. Схема лежит в architecture.md
2. Развернута БД (Supabase или PostgreSQL в Docker), агент подключён через MCP
3. Настроены auth и RLS, политики проверены агентом (негативные тесты доступа)
4. Собран API по спеке через TDD: основной CRUD + 1 бизнес-сценарий с тестами
5. Фронт подключён к API: живые данные, обработка ошибок, CORS настроен

Опционально: 1 AI-фича через OpenRouter / YandexGPT со structured output и лимитами

В README описано что сделано, скрин работающего сценария, ссылка на GitHub.
