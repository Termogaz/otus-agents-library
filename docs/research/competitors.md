# Анализ аналогов

Исследование к ДЗ-3 (2026-10-31): что взять у похожих продуктов в фичах, UX и UI.
Вывод «берём / не берём» проверен по коду проекта. Окончательное решение по составу PRD принимает автор.

## Рынок и позиционирование

| Сегмент                | Примеры                               | Кому                                | Что важно                                 |
| ---------------------- | ------------------------------------- | ----------------------------------- | ----------------------------------------- |
| Открытые системы (ILS) | Koha, Evergreen                       | Библиотеки с технической поддержкой | Лицензия бесплатна, настройка сложнее     |
| Лёгкие облачные        | Libib, TinyCat, Simple Little Library | Небольшие организации, школы, дома  | Запуск без администратора, платные тарифы |
| Школьные системы       | Follett Destiny                       | Школы и округа (K-12)               | Цена не опубликована                      |

**Наша ниша:** один библиотекарь в небольшой библиотеке. Ближайший аналог по задаче — Libib, поэтому его UX главный
референс. Koha и Evergreen полезны как образцы обработки отказов при выдаче.

Сегменты собраны по агрегаторам (FitGap, Capterra, G2), где мало отзывов: это ориентир, а не измерение рынка.

| Срок                | Подставлен, меняется кликом по дате                      | Из правил, можно задать вручную                                 | Вычисляется, можно задать вручную                       | 14 дней, правило в домене                        |

## Визуальные наблюдения

Виден только интерфейс на снимках из документации. Цвета названы на глаз: снимки могут быть старше текущих версий,
а точные значения для проекта подбираются на шаге `DESIGN.md`.

- **Libib.** Много белого пространства, бирюзовый акцент на кнопках и активной вкладке, нейтральный шрифт без засечек.
  Просроченная строка бледно-красная. Названия книг жирные, авторы серые: иерархия держится на начертании и цвете текста.
- **Koha.** Светло-серый фон, белые панели, зелёный цвет вкладок и ссылок, жёлтая основная кнопка.
  Плотная служебная раскладка: удобна профессионалу, тяжела для одного библиотекаря.
- **Evergreen.** Похоже на типовой веб-интерфейс Bootstrap: синяя активная вкладка, таблица-реестр с множеством колонок,
  дата выдачи в виде таблицы. Запоминающегося стиля нет.

Кандидаты для критики PRD на шаге 2. «Новое» означает, что требования ещё нет.

| --- | ---------------------------------------------------------------------------------- | --------- | -------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1   | Причина отказа прямо над полем действия                                            | Koha      | Уже FR-2, уточняет место   | Только клиент                                                                                         |
| 2   | Текст в пустом списке                                                              | Koha      | Уже FR-1                   | Только клиент                                                                                         |
| 3   | Просроченная строка выделена целиком, не только статус                             | Libib     | Уточняет FR-4              | Только клиент: API отдаёт `overdue`                                                                   |
| 4   | Выдачи отсортированы: просроченные и ближайшие по сроку сверху, возвращённые внизу | Libib     | **Новое**                  | Только клиент: есть `dueAt` и `returnedAt`                                                            |
| 5   | При выборе читателя видно «На руках: N»                                            | Libib     | **Новое**                  | Только клиент, считается из выдач. **«N из 3» нельзя:** лимит есть только в домене, API его не отдаёт |
| 6   | Подсказка о свободных экземплярах под выбранной книгой                             | Libib     | **Новое**, смягчает запрет | Только клиент: есть `available`. Текст варианта менять нельзя, см. ниже                               |

| 8   | Выдача как первый и главный блок страницы                                          | Libib     | Раскладка, не требование   | Только клиент; порядок блоков e2e не проверяет                                                        |
| 9   | Понятные строки формы: жирное название, серый автор                                | Libib     | Раскладка, в `DESIGN.md`   | Только CSS и разметка                                                                                 |

## Что не берём

| Что                                            | Откуда                 | Почему                                                                                                            |
| ---------------------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Вкладки вместо одной страницы                  | Libib, Koha, Evergreen | `tests/e2e/loans.spec.ts` заполняет формы подряд без переключений; скрытая форма сломала бы тест, а его не меняем |
| Метка или запрет в списке книг без экземпляров | Libib                  | e2e выбирает вариант по точному названию и ждёт отказ сервера «Нет свободных экземпляров»                         |
| Штрихкоды, сканер, режим возврата              | Все                    | Нет поля в данных, нужна миграция; в сценарии нет сканера                                                         |
| Резервы и самовыдача читателем                 | Libib, Koha            | Новая доменная область и другая роль                                                                              |
| Обход лимита подтверждением                    | Koha, Evergreen        | Лимит 3 — правило домена, у библиотекаря нет полномочий его менять                                                |
| Смена срока вручную                            | Все                    | Срок 14 дней задан доменом, API его не принимает                                                                  |
| Пени и письма читателю                         | Koha, Libib            | Нужны сервер и новые данные; решение Discovery ДЗ-2 — не в этом объёме                                            |
| Обложки книг                                   | Libib                  | Нет данных и внешнего источника; добавит сетевую зависимость                                                      |
| Горячие клавиши                                | Koha                   | Без сканера и большого потока книг выгода мала; достаточно порядка фокуса и видимого фокуса                       |

## Источники

Первоисточники прочитаны 2026-10-31; снимки экранов из документации лежат локально в `.local/hw3-refs/` и в git не входят.

- Libib: [главная](https://www.libib.com/), [тарифы](https://www.libib.com/pricing), [выдача](https://support.libib.com/libib/website/lending.html).
- Koha: [сайт](https://koha-community.org/), [руководство, Circulation](https://koha-community.org/manual/latest/en/html/circulation.html). Страница длинная: дословно прочитана первая половина, остальное по пересказу.
- Evergreen: [документация 3.16, Circulating Items](https://docs.evergreen-ils.org/docs/3.16/circulation/circulating_items_web_client.html). Дословно прочитано около половины страницы.
- Рынок: [FitGap](https://us.fitgap.com/search/library-management-systems), [Capterra, альтернативы Koha](https://www.capterra.com/p/153941/Koha/alternatives/), [G2, Evergreen и Koha](https://www.g2.com/compare/evergreen-ils-vs-koha).

**Что не подтверждено.** Позиционирование и лицензия Evergreen: сайт вернул страницу защиты от ботов, а аналог отнесён к открытым
системам только по агрегатору. Лицензия Koha на прочитанных страницах не названа. Живые экраны не открывались,
поэтому UI оценён по снимкам из документации. Цены Libib взяты с их страницы тарифов и расходятся с агрегаторами.
