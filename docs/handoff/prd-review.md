## Что оспорено, но оставлено

- **Заморозка домена и API.** Часть отвергнутых идей дешевле с новым API (лимит в ответе), но ДЗ оценивает концепцию,
  а не расширение сервера. Менять контракт ради одной подписи нецелесообразно.
- **Лимит CSS 20 КБ.** Число условное: это страховка от случайно подключённого CSS-набора, а не целевой показатель.
  Сейчас в проекте CSS нет, поэтому размер проверяется после реализации.

## Реализуемость

| Вопрос                   | Оценка             | Основание                                                                                                                              |
| ------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| Данные                   | Да                 | Клиент уже получает `available`, `copies`, `dueAt`, `returnedAt`, `overdue`, `readerId`; `POST /api/loans` возвращает выдачу со сроком |
| Стек и зависимости       | Да                 | Достаточно React и CSS, новых пакетов нет                                                                                              |
| Архитектура              | Да, с условием     | Сортировка и счётчики только для показа; решение о выдаче остаётся в домене. Просрочку клиент берёт из `overdue`, а не считает         |
| Совместимость с e2e      | Да, с условиями    | Ограничения перечислены в PRD; при реализации запускать `npm run test:e2e`                                                             |
| Проверяемость            | Да                 | FR-3 и FR-5 требуют перехвата запросов в Playwright (`page.route`): задержка и сбой обновления списка                                  |
| Трудоёмкость             | Небольшая          | Правки только в `src/client` и новый CSS; оценка экспертная, в этом ДЗ код не пишется                                                  |
| Главный технический риск | Средний            | FR-2 и FR-5 требуют разделить в `App.tsx` действие и обновление списка и хранить, где произошла ошибка. Это основа остальных изменений |
| Спрос на продукт         | **Не подтверждён** | Пользователей и интервью нет. Libib Pro за $9 в месяц уже даёт выдачу, поэтому как рыночный продукт идея преимущества не показывает    |

**Вывод.** Для учебной цели идея жизнеспособна: объём посилен и не задевает домен. Для рынка её жизнеспособность не доказана:
единственная гипотеза ценности — простая бесплатная система на своём компьютере для одной небольшой библиотеки. Без разговора с
реальными библиотекарями она остаётся гипотезой, поэтому коммерческих выводов этот документ не делает.
