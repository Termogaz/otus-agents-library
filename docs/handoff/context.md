## Текущее состояние кода

- Интерфейс: `src/client/App.tsx`, `src/client/api.ts`. Файлов CSS в `src/client` нет.
- `App.tsx`, функция `run()`: действие и обновление списка идут в одном `try`, поэтому сбой обновления выглядит как отказ.
  Разделение этих шагов лежит в основе FR-2 и FR-5.
- API отдаёт `BookView.available`, `BookView.copies`, `LoanView.dueAt`, `returnedAt`, `overdue`, `readerId`.
  `POST /api/loans` принимает `{bookId, readerId}` и отвечает `201` с выдачей, включая срок.
- Лимит и срок заданы в `src/domain/loans.ts` (`DEFAULT_LOAN_POLICY`: 3 книги, 14 дней). API лимит не отдаёт.

## Решения автора

- Новые фичи из аналогов: порядок строк по сроку, «На руках: N», «Свободно: N из M».
- Якоря со счётчиками не берём.
- Оптимистичный UI и тёмная тема не входят в объём.
- Экраны — разделы и состояния одной страницы, без маршрутизации.
