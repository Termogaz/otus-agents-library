# ДЗ-2. Построение агентно-ориентированного пайплайна разработки

Текст задания курса OTUS «ИИ-агенты: продвинутое внедрение и использование», модуль 2.
Источник требований для вехи GSD `.planning/ROADMAP.md`.

## Цель

Настроить окружение, выстроить структуру проекта, внедрить контекстную инженерию и
инициировать цикл разработки с AI-агентом.

## Пошаговая инструкция

1. Установить gsd-core, инициирован проект (Roadmap, plan, progress, architecture, security-checklist).
2. Подключена память для агента (Claude Mem или аналог).
3. Настроены быстрые команды и auto hooks.
4. Внедрён инструмент управления контекстом (автосжатие/чек-пойнты), приложен скрин usage до и после.
5. Пройден этап Discovery в фреймворке GSD или аналогичном.

## Критерии оценки

Подготовлено окружение под конкретный проект, и в README описаны результаты 2-го модуля для проверки.
