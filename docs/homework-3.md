# ДЗ-3. Продуктовая аналитика и визуальная концепция

Текст задания курса OTUS «ИИ-агенты: продвинутое внедрение и использование», модуль 3.

## Цель

Почелленжить PRD с AI-агентом, подсобрать референсы UX, UI для вашего проекта.

## Пошаговая инструкция

1. Найти аналоги своего проекта, скопировать фичи, UX, UI.
2. Набдить агента полным контекстом (ресерч, анализ конкурентов).
3. Пройти фазу gsd-plan-phase и gsd-discuss-phase.
4. Подготовлены UX-паттерны (экраны, переходы).
5. Подобраны цвета для UI.

## Критерии оценки

Собран контекст и проработана визуальная концепция.

## Компетенции

**Генерация и валидация продуктовых идей**

- использовать AI для брейнсторминга и ресёрча рынка;
- проводить оценку жизнеспособности идеи с помощью AI;
- знать основы Product Management и продуктовой стратегии;
- знать методики исследования рынка и конкурентов;
- знать проверку жизнеспособности идеи (Feasibility check);
- готовить контекст о проекте для агента.

**Проектирование UI/UX и составление ТЗ**

- создавать User Stories и Acceptance Criteria;
- проектировать пользовательские сценарии и обработку ошибок;
- знать основы UX и User Story Mapping;
- знать паттерны UX и обработки ошибок;
- знать подбор цвета, референсов и брендинга (design.md);
- знать handoff-пакет: PRD, User Stories, acceptance criteria;
- подбирать цвета и UX/UI-референсы, собирать design.md;
- структурировать техническое задание для AI-агента.
