# Security-checklist среды агента

Перечень рисков из `.planning/codebase/CONCERNS.md` и запретов ДЗ-1: у каждого пункта есть команда проверки и статус «закрыт» или «открыт». «Воспроизводим из git» = «да», если защита живёт в закоммиченных файлах и после `git clone` и `npm ci` работает без ручной настройки. Hooks и deny-шаблоны — эвристика по шаблонам, а не песочница (см. [`about.md`](about.md)): подстановки `$VAR` и `$(...)`, глобы вида `.e*` и интерпретаторы (`python -c`, `node -e`) hook не раскрывает.
